# 首页功能模块说明

> 记录日期：2026-09-27  
> 对应页面：应用首页 `Explore other use cases`

## 1. 卡片上的 “N Models” 是什么意思

`4 Models`、`7 Models` 表示当前模型清单中有多少个模型声明支持这个功能，**不表示手机已经下载了多少个模型**。

例如 `Ask Image` 显示 `4 Models`，表示 Gemma 4 E2B/E4B 和 Gemma 3n E2B/E4B 都可以用于图片问答。只下载 Gemma-4-E2B-it 后，也能直接使用该功能。

## 2. 模块总览

| 模块 | 核心用途 | 当前兼容模型 | 是否使用 Gemma-4-E2B-it |
| --- | --- | ---: | --- |
| Agent Skills | 带 Skill、MCP 和工具的 Agent 聊天 | 2 | 是 |
| Ask Image | 对图片进行问答和分析 | 4 | 是 |
| Audio Scribe | 音频转写、翻译和总结 | 4 | 是 |
| Prompt Lab | 单轮 Prompt 和生成参数实验 | 7 | 是 |
| Tiny Garden | 自然语言控制种花小游戏 | 1 | 否，使用 TinyGarden-270M |
| Mobile Actions | 自然语言触发手机操作 | 1 | 否，使用 MobileActions-270M |
| Scrapbook | 图片抠图、编辑和拼贴 | 1 | 否，使用 Magic touch 分割模型 |

模型数量来自当前 `model_allowlists/1_0_19.json`。

## 3. Agent Skills

这是普通 AI Chat 的增强版本。模型不仅回答文字，还可以读取 Skill 指令并决定调用工具。

代码中支持的扩展包括：

- 加载和管理 Skill。
- 执行 Skill 中的 JavaScript。
- 连接 MCP Server 并调用 MCP 工具。
- 调用 Android Intent 类工具。
- 展示工具返回的图片或 WebView 内容。
- 对敏感 MCP 工具调用弹出权限确认。

适合场景：需要模型分步骤完成任务、查询外部信息、生成交互式结果或调用第三方工具。

注意：模型推理可以本地完成，但 Skill、MCP Server 或外部数据源可能需要联网，并可能需要 API Key。第三方 Skill 本质上具有执行能力，添加前应检查来源和权限。

当前兼容：Gemma-4-E2B-it、Gemma-4-E4B-it。

## 4. Ask Image

让多模态模型理解图片并回答问题。

常见用法：

- 描述图片内容。
- 识别物体、场景和图表。
- 阅读图片中的文字。
- 根据图片回答具体问题。
- 对截图、作业题或设备照片进行解释。

它不是绘图或图片生成模块，只负责“看图并输出文字”。使用相机或相册时需要对应权限。

当前兼容：Gemma 4 E2B/E4B、Gemma 3n E2B/E4B。

## 5. Audio Scribe

让支持音频输入的模型处理录音或音频片段。

主要用途：

- 语音转文字。
- 音频翻译。
- 会议或录音内容总结。
- 针对音频内容进行问答。

它不是专业音频编辑器，也不是音乐生成模块。录音需要麦克风权限；处理速度与音频长度、模型大小和设备性能有关。

当前兼容：Gemma 4 E2B/E4B、Gemma 3n E2B/E4B。

## 6. Prompt Lab

用于单轮 Prompt 实验，不强调多轮对话历史。

内置方向包括：

- 自由 Prompt。
- 改写语气。
- 文本摘要。
- 代码片段任务。
- 预览最终组合出的 Prompt。
- 调整温度、Top-K、Top-P、最大输出长度等生成参数。

适合开发者比较不同模型和参数的输出效果。它与 AI Chat 的区别是：AI Chat 面向连续对话，Prompt Lab 面向可重复的单次实验。

当前兼容 7 个通用文本/多模态模型，包括 Gemma 4、Gemma 3n、Gemma3 1B、Qwen2.5 1.5B 和 DeepSeek-R1 Distill Qwen 1.5B。

## 7. Tiny Garden

这是 Function Calling 的演示小游戏。界面中有一个 3×3 花园，用户用自然语言控制游戏。

示例指令：

- “在第一排种向日葵。”
- “给左边一列浇水。”
- “收获 1、2、3 号地块。”

模型会把自然语言转换成 `plantSeed`、`waterPlots`、`harvestPlots` 等结构化函数调用，再由应用更新游戏界面。

它使用专门微调的 `TinyGarden-270M`，不是 Gemma-4-E2B-it。该模块可完全离线运行，重点是展示小模型的函数调用能力，而不是通用问答能力。

## 8. Mobile Actions

这是另一个 Function Calling 演示：模型把自然语言转换为 Android 操作。

当前源码定义的示例动作包括：

- 打开/关闭手电筒。
- 创建联系人。
- 编写并发送邮件。
- 在地图中显示地点。
- 打开 Wi-Fi 设置。
- 创建日历事件。

它使用专门微调的 `MobileActions-270M`，不是通用 Gemma 4 模型。部分动作会启动系统页面或需要权限/用户确认，不应理解为模型可以无条件控制整个手机。该功能属于实验演示，复杂或表述含糊的命令可能识别错误。

## 9. Scrapbook

这是图片处理功能，不是大语言模型聊天功能。它使用 MediaPipe Interactive Segmenter 和名为 `Magic touch` 的交互分割模型。

主要流程：

1. 从图片中选择一个主体。
2. 模型把主体从背景中分割出来，形成 cutout（抠图素材）。
3. 对抠图进行编辑和管理。
4. 选择背景、叠放多个抠图，制作拼贴画或 scrapbook。
5. 保存或分享最终图片。

页面包含创建抠图、拼贴和管理已有抠图等标签。它生成的是图片拼贴，不是视频，也不使用 Gemma-4-E2B-it。

## 10. 推荐体验顺序

已经下载 Gemma-4-E2B-it 时，建议：

1. `AI Chat`：先确认模型能够正常初始化和输出。
2. `Ask Image`：体验图片理解。
3. `Audio Scribe`：体验录音转写和音频理解。
4. `Prompt Lab`：对比 Prompt 和生成参数。
5. `Agent Skills`：理解 Skill/MCP 和工具调用。
6. 再分别下载专用小模型体验 Tiny Garden、Mobile Actions 和 Scrapbook。
